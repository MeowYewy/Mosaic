## 产品目标

本地处理病历 / 报告等文件：导入 → OCR/文本识别 → 自动脱敏框 → 人工复核 → 不可逆导出。

## 界面结构

| 区域 | 能力 |
|------|------|
| 左侧 | 拖入/浏览 PDF、DOCX、PNG、JPEG；类型标签；拖拽排序；确认预览；导出 |
| 右侧 | 原图+框 / 脱敏效果；绘制·选择工具；色块/马赛克；Ctrl+滚轮缩放；多页翻页 |

## 脱敏策略

1. **不可逆**：像素层色块或马赛克，导出后无法从图片还原原文
2. **自动识别（v0.1）**
   - 身份证（18 位校验）、手机号、姓名标签、病历号
   - **OCR**：Tesseract `chi_sim+eng`，词级坐标 → 脱敏框（扫描件/PDF 页）
   - **文本层回退**：DOCX/PDF 无 OCR 时按行估算（需复核）
3. **人工复核**：自动框为辅助，导出前必须检查

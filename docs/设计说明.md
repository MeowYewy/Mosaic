## 产品目标

**Mosaic** 提供本地 PDF 工具箱与文档脱敏：导入 → 预览 → 处理/标注 → 导出，数据不出本机。

## 界面结构

| 模式 | 能力 |
|------|------|
| PDF（主页） | 拆分 / 合并 / 旋转 / 转换 / 压缩 / 水印 |
| 脱敏 | 拖入/浏览 PDF、DOCX、PNG、JPEG；排序；手动脱敏框；导出 |

顶栏与窗口标题统一为 **Mosaic**；Tab 栏「脱敏」进入脱敏模式。

## 脱敏策略

1. **不可逆**：像素层色块或马赛克
2. **自动识别（代码在库，v0.1 暂关）**：Tesseract OCR + 规则
3. **人工复核**：导出前必须检查
